KBO 데이터 명세와 화면 구성안

2026 KBO 시즌 기록을 입력으로 사용하는 가상야구 앱의 현재 데이터 구조와 6개 화면 배치입니다. 화면·엔진 연결과 원격 데이터 로딩은 구현되어 있으며, 개인 기록의 기기 저장과 중단 경기 복구는 후속 작업입니다.

버전 안내초안 원본초안과 차이데이터 명세화면 구성남은 작업
아래 화면은 현재 소스의 정보 순서와 고정 영역을 나타낸 배치도이며 앱 스크린샷이 아닙니다. 점수·선수·시즌 성적 예시를 임의로 넣지 않고 표시 항목을 설명합니다. 초안의 기존 수집 현황과 구현 예정 표기는 당시 기록으로 보존합니다.

배치 설명 → 어두운 예측 점수판 → 지난 경기(조건부) → 데이터 안내(조건부) → 정규시즌 순위 순서로 내용 영역을 스크롤합니다. 점수판은 스크롤 내용에 포함되며, 경기 만들기·개인 기록 버튼은 하단 고정입니다. 빈 지난 경기 칸과 별도의 새 경기 안내 칸은 표시하지 않습니다.

점수판 누적 점수·예측 경기 수·적중률을 표시합니다. 예측 0건이면 적중 100점·무승부 0점 및 적중률 제외 안내, 기록이 있으면 적중·빗나감·무승부 건수를 표시합니다. 적중률은 적중 수 ÷ 승패가 갈린 경기 수이며, 분모가 0이면 —로 표시합니다.

순위표 준비 완료 시 시즌 데이터의 팀을 승률 내림차순으로 표시합니다. 순위·팀 약칭·승·패·무·승률·차를 표시하며, 승률은 승 ÷ (승 + 패)입니다. 같은 승률은 공동 순위로 표시하고 다음 순위는 건너뜁니다. 게임 차는 ((1위 승 − 1위 패) − (해당 팀 승 − 해당 팀 패)) ÷ 2이며, 차가 0이면 —, 정수는 정수로, 반 경기는 소수 한 자리로 표시합니다. 앱에서 치른 가상 경기 결과로 시즌 순위를 변경하지 않습니다.

상태·동작 점수판은 로딩·실패 중에도 표시합니다. 시즌 순위 영역은 로딩 중 진행 표시와 안내, 실패 시 오류 사유·다시 불러오기로 대체합니다. 준비 완료이고 기록이 있을 때만 지난 경기 최대 5개를 표시합니다. 데이터 안내가 있으면 순위표 앞에 표시하고 재시도 가능 시 다시 불러오기를 제공합니다. 데이터 ready일 때만 경기 만들기·개인 기록을 활성화하며 각각 팀 선택·개인 기록 화면으로 이동합니다. 시즌 연도는 준비된 데이터의 year를 사용하고 준비 전 또는 빈 값이면 2026을 사용합니다.
