### 초안 (사용자 원문)
1. 메인화면
2026시즌 정규리그 순위표를 보여줌
- 네이버 스포츠 순위표마냥 팀별 앰블럼이랑 팀이름 같이 보여줌
- 지금까지 진행한 경기수와 승률, 획득한 점수를 보여줌

2. 시뮬레이션 준비화면
시뮬레이션 돌릴 두 팀을 지정 -> 선발투수 고르기 (실제로 선발투수로 뛴 기록이 있는 선수만 고를수 있도록) -> 라인업 확인 (기본으로 9명의 라인업이 꾸려지지만 사용자의 취향에 따라 라인업을 조정할수 있도록) -> 경기 시작

3. 경기중
기존 시스템 유지

4. 경기 결과
승리투수, 패배투수, 홀드/세이브 투수 보이게 구현
결과 화면에서는 스코어보드를 통해 간략하게만 결과를 보여주고 상세보기 버튼을 통해 각 타자와 투수의 경기 상세결과를 보여줌
다시하기 버튼을 누르면 2번으로 돌아감
처음으로 버튼을 누르면 1번으로 돌아감

- 가장 중요한 것: (아직 받지 않음)
- 레퍼런스: 네이버 스포츠 순위표 스크린샷 1장 / 가져오고 싶은 점: "팀 순위표는 이런식으로 제작해주고" (팀별 앰블럼과 팀이름을 같이 보여주는 순위표)
- 삭제 범위 (사용자 원문): "화면을 구성하는 요소빼고 dart 엔진은 날리지 말아줘"
- 빈칸: 가장 중요한 것 (두 번 물었으나 답 없음)

### 레퍼런스 관찰 (스크린샷, 측정 못 함)
- 열: 순위 · (엠블럼+팀명+›) · 승률 · 게임차 · 경기 · 승 · 패 · 무 · 연속 · 타율 · 평균자책
- 정렬 기준 열(승률)만 파란 굵은 글자, 헤더 글자도 파랑. 나머지 숫자는 검정 보통 굵기, 가운데 정렬
- 순위 숫자는 회색 굵은 글자. 팀 칸은 작은 엠블럼 + 팀 짧은 이름 + 오른쪽 꺾쇠(›)
- 헤더 줄은 흰 바탕, 데이터 줄은 옅은 회청색 바탕에 얇은 가로 구분선. 세로 구분선 없음
- 10팀이 한 화면에 모두 보이는 촘촘한 줄 높이

### AI 구조안
1. 메인
   - 위: 내 기록 한 줄(진행한 경기 수 · 적중률 · 누적 점수). 누르면 개인 기록 화면
   - 가운데: 2026 정규시즌 순위표. 순위 · 팀 표식+팀명 · 승률(강조) · 게임차 · 경기 · 승 · 패 · 무 · 타율 · 평균자책. 휴대폰 폭에서는 순위·팀 칸을 고정하고 숫자 열은 가로로 밀어서 봄
   - 중단된 경기가 있으면 순위표 위에 "이어하기" 카드
   - 아래: 주 버튼 "시뮬레이션 시작" → 2
2. 시뮬레이션 준비 (한 화면, 단계 표시)
   - ① 두 팀 고르기 (원정 / 홈)
   - ② 양 팀 선발투수 고르기: 시즌 선발 출장 기록이 1번 이상인 투수만, 시즌 기록과 함께
   - ③ 라인업 확인: 기본 9명. 타순 바꾸기, 같은 팀 다른 타자로 바꾸기
   - ④ 승리 팀 예측 (확정하면 못 바꾼다는 안내)
   - 주 버튼 "경기 시작" → 3
3. 경기 중: 기존 기능 그대로 (문자중계 피드, 점수·이닝·아웃, 예측한 팀만 투수 교체·대타). 화면 모양만 새 디자인에 맞춤
4. 경기 결과
   - 스코어보드(이닝별 점수 + R/H/B)
   - 승리투수 · 패전투수 · 세이브 · 홀드
   - 예측 적중 여부와 얻은 점수
   - 버튼: 상세보기 / 다시하기(→2) / 처음으로(→1)
   - 상세보기: 타자별(타수·안타·홈런·타점·볼넷·삼진), 투수별(이닝·피안타·실점·볼넷·삼진)
5. 개인 기록: 지금 기능 유지, 메인의 내 기록 줄에서 들어감
- 가장 강조하는 것: 메인은 순위표, 결과는 스코어보드
